# Kaaladrishti — Protobuf Contract Reference

## Overview

The canonical protobuf schema lives at:
`proto/kaaladrishti/v1/platform.proto`

It is shared verbatim by all three language planes. Generated bindings are
produced by `scripts/gen_proto.sh` and stored in `generated/{rust,go,python}/`.

## Package & Versioning

```protobuf
syntax = "proto3";
package kaaladrishti.v1;
option go_package = "github.com/kaaladrishti/engine/generated/go/kaaladrishti/v1;kaaladrishtiv1";
```

New fields must be additive. Field numbers and types are immutable once deployed.

## Message Groups

### Telemetry (Rust → Go via UDS)
| Message | Purpose |
|---|---|
| `TelemetryEvent` | Atomic telemetry unit; `oneof payload` for typed dispatch |
| `ProcessEvent` | Process spawn/terminate/module-load |
| `NetworkEvent` | Network connection with direction, bytes |
| `IdentityEvent` | Auth/authz changes, privilege escalation |
| `FileEvent` | File reads/writes/deletes |
| `RegistryEvent` | Windows registry operations |

## gRPC Service

```
service MLAnalyticsService {
  rpc ScoreRisk(RiskScoreRequest) returns (RiskScoreResponse);
  rpc ComputeBlastRadius(RiskScoreRequest) returns (BlastRadius);
  rpc ForecastNextAttack(NextAttackForecastRequest) returns (NextAttackForecastResponse);
  rpc ScoreIntentLineage(IntentLineageRequest) returns (IntentLineageResponse);
  rpc EvaluateDrift(DriftEvaluationRequest) returns (DriftEvaluationResponse);
}
```

Go is always the caller. Python never initiates calls.
